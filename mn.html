Testing that keeps code reliable

Each testing layer checks a different part of your application.

🧪

Unit Testing

Verifies small, individual pieces of code independently. It helps identify errors in methods and business logic before they spread to other components.

JUnit 5 · Mockito
Example: test whether a calculator method correctly returns the sum of two numbers. Mock external dependencies when isolation is needed.
🔌

Integration Testing

Checks whether multiple application components work together correctly, including controllers, services, databases and REST endpoints.

Spring Boot · MockMvc
Example: send a simulated HTTP request to a Spring controller using MockMvc and verify the status code and response. Use Testcontainers when testing against real databases or Kafka.
🤝

Contract Testing

Ensures that a service provider follows the API expectations agreed upon with its consumer. It helps detect breaking changes between services.

Pact
Example: a frontend expects a user API to return an ID and name. Pact helps verify that the backend response satisfies the defined consumer contract.
🐳

Testcontainers

Starts disposable Docker containers for dependencies so tests can run against realistic infrastructure rather than relying only on mocks.

Docker · Database · Kafka
Example: start a temporary PostgreSQL or Kafka container during a test, execute application operations, and dispose of the container afterward.
